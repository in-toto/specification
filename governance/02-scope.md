# Scope

This Working Group standardizes the in-toto framework for securing the integrity of software supply chains. In scope: the layout metadata format that defines a supply chain, the link metadata format that records evidence of each step, the roles (project owner, functionaries, and clients), artifact rules, and the verification workflow. Out of scope: specific language implementations, key management and distribution, the attestation format (a separate specification), and transport.

Any changes of Scope are not retroactive.
